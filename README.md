## Publicar en GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube `index.html`, `tortuga.jpg` y `loose-market.jpg` al nivel raíz.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige `main` y `/ (root)` y guarda.
6. GitHub te mostrará la URL pública del sitio.

El sitio usa únicamente HTML/CSS/JS, por lo que GitHub Pages puede alojarlo directamente.
